# Krich_fran — сайт-портфолио

Одностраничный сайт: чистый HTML, CSS и JavaScript. Без сборщиков, фреймворков
и зависимостей — кладётся на любой хостинг как есть.

---

## Запуск

```
python dev-server.py
```

Откроется на <http://localhost:5173>.

Это обычный статический сервер с одним отличием: он запрещает кеширование.
Штатный `python -m http.server` не шлёт заголовки кеша, и браузер держит в
кеше файлы, подключённые через `@import` — правки CSS перестают доезжать без
ручного сброса.

`index.html` можно открыть и двойным кликом: скрипты подключены обычными
`<script defer>`, а не ES-модулями, которые протокол `file://` блокирует.

## Где что править

| Что нужно изменить | Файл |
|---|---|
| Работы в портфолио | `assets/js/data/projects.js` |
| Группы и подгруппы работ | `assets/js/data/groups.js` |
| Любой текст интерфейса (RU/EN) | `assets/js/data/i18n.js` |
| Цвета, шрифты, отступы, тайминги | `assets/css/base/tokens.css` |
| Структура страницы | `index.html` |

### Добавить работу

1. Положите файлы в `assets/media/works/` (или пропустите их через
   `tools/build-media.ps1`, см. ниже).
2. Допишите объект в массив в `projects.js`.

Карточка соберётся сама, счётчики и чипы фильтра пересчитаются, порядок на
странице совпадает с порядком в массиве.

Поля работы описаны в шапке `projects.js`. Необязательные: `desc`, `year`,
`link` — если их нет, соответствующие элементы просто не выводятся.

### Сменить акцентный цвет

В `assets/css/base/tokens.css` — четыре переменные: `--c-accent` (заливки),
`--c-accent-text` (акцент в тексте), `--c-accent-ink` (текст поверх заливки)
и `--c-accent-soft`. Они заданы отдельно для тёмной и светлой темы: чистый
лайм читается на тёмном, но не на белом, поэтому в светлой теме акцент-текст
затемнён до `#3D6300`.

## Скрипты

### `tools/build-media.ps1`

Готовит исходники работ к вебу: жмёт картинки, кодирует видео, режет из
записей экрана интерфейс Roblox Studio, снимает постер-кадры, перекодирует
аудио. Манифест в начале файла показывает, из какого исходника выросла каждая
работа.

Нужен `ffmpeg` в `PATH`. Путь к папке с исходниками задан в переменной `$Src` —
поправьте под себя.

Исходные 130 МБ превращаются в 22 МБ.

### `tools/build-css.ps1`

Склеивает стили в `assets/css/main.build.css` и вырезает комментарии.

В разработке `main.css` подключает 33 файла через `@import` — это удобно
править, но браузер грузит их цепочкой. Перед выкладкой:

```
powershell -ExecutionPolicy Bypass -File tools\build-css.ps1
```

затем в `index.html` замените `assets/css/main.css` на
`assets/css/main.build.css`. Исходники при этом остаются на месте.

> Оба скрипта должны быть сохранены в UTF-8 **с BOM**: Windows PowerShell 5.1
> читает `.ps1` без BOM как ANSI и ломает кириллицу в путях.

## Публикация

Сайт живёт на GitHub Pages: <https://vlapetrushkin-dot.github.io/sroki/>

Достаточно запушить в `main` — Pages подхватят изменения за минуту-другую.

**`.nojekyll` в корне трогать нельзя.** GitHub Pages по умолчанию прогоняет
репозиторий через Jekyll, а тот не отдаёт файлы, чьи имена начинаются с
подчёркивания. У нас такой есть — `assets/css/motifs/_motif-base.css`, и без
него все мотивы дисциплин остались бы без базовых стилей. Пустой файл
`.nojekyll` эту обработку отключает.

При смене домена поправьте адрес в трёх местах: `index.html` (`og:image`,
`og:url`), `robots.txt`, `sitemap.xml`. Относительный `og:image` соцсети не
понимают — нужен абсолютный.

OG-картинка — `assets/img/og/cover.jpg`, 1200×630. Пересоздать можно тем же
ffmpeg из любой работы.

## Что стоит знать о поведении

**Форма ничего не отправляет.** Сайт статический: отправлять письма неоткуда,
а токен Telegram-бота в исходниках страницы увидел бы любой желающий. Поэтому
кнопка собирает текст заявки, копирует его в буфер и открывает чат — остаётся
вставить. Если появится бэкенд или бот, менять нужно только функцию `submit()`
в `assets/js/modules/form.js`.

**Секция работ требует JavaScript.** Карточки собираются из `projects.js`:
пятнадцать работ с галереями раздули бы разметку, а список правится часто.
Остальные секции — текст в самом HTML и читаются без скриптов.

**Базовый язык разметки — английский.** Тексты лежат прямо в HTML, чтобы их
видели поисковики и пользователи без JS. Русский подставляется автоматически,
если язык браузера русский; выбор запоминается.

**Переходы глушатся на время смены темы.** Chromium не перезапускает уже
объявленный `transition`, когда меняется только значение CSS-переменной внутри
него: элемент остаётся с цветом прежней темы. Класс `is-theme-switching`
отключает переходы на один кадр — см. `assets/css/base/reset.css` и
`assets/js/modules/theme.js`. Если будете добавлять анимации цвета, помните об
этом.

**Мотивы дисциплин анимируются только при наведении** и не ставятся на паузу,
а просто не назначаются до `:hover`. Пауза удерживала бы нулевой кадр, а у
половины мотивов он пустой — карточка выглядела бы недорисованной.

## Структура

```
index.html              разметка всех секций
dev-server.py           локальный сервер без кеширования
robots.txt, sitemap.xml
favicon.svg

assets/
  css/
    main.css            точка входа, собирает остальное через @import
    base/               токены, сброс, типографика
    layout/             контейнер, шапка, подвал
    components/         кнопки, бейджи, карточки, лайтбокс, плеер, формы
    sections/           стили конкретных секций
    motifs/             девять мотивов дисциплин, только декор
  js/
    main.js             порядок инициализации модулей
    data/               работы, группы, словарь RU/EN
    modules/            тема, язык, навигация, работы, фильтры,
                        лайтбокс, плеер, форма, появление при скролле
  media/works/          подготовленные файлы работ
  img/og/               картинка для соцсетей

tools/                  скрипты подготовки медиа и сборки CSS
```

Модули общаются через объект `window.App` и подключаются обычными
`<script defer>` — порядок подключения в конце `index.html` важен:
данные, затем утилиты, затем модули, затем `main.js`.
